### DANH SÁCH SỰ KIỆN REAL-TIME (SOCKET.IO DICTIONARY)

| Tên Event (Event Name)       | Người gửi (Actor)        | Dữ liệu (Payload - JSON)                                                                                                                                      | Mô tả chi tiết (Description)                                                                                                                    |
| :--------------------------- | :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| `customer:subscribe`         | Khách hàng -> Server     | `{ "trip_id": "string (optional)" }`                                                                                                                          | Khách hàng xin join vào room cá nhân hoặc room chuyến đi (`trip_${id}`) để theo dõi tiến trình và tài xế.                                       |
| `driver:subscribe`           | Tài xế -> Server         | `{}` (Identity lấy từ JWT Token)                                                                                                                              | Tài xế báo cáo sẵn sàng nhận tín hiệu, join vào room cá nhân (`driver_${id}`) để nhận cuốc xe (Dispatchs).                                      |
| `driver:update_location`     | Tài xế -> Server         | `{ "latitude": 10.762, "longitude": 106.660, "heading": 90, "speed": 45, "trip_id": "string (optional)" }`                                                    | **(SYS-01)** Tài xế gửi vị trí liên tục mỗi 3-5 giây. Nếu đang trong chuyến đi (`trip_id != null`), vị trí này sẽ được phát lại cho khách hàng. |
| `server:dispatch_offer`      | Server -> Tài xế         | `{ "offer_id": "string", "pickup": { "lat": 10.1, "lng": 106.2 }, "dropoff": { "lat": 10.2, "lng": 106.3 }, "estimated_fare": 50000, "timeout_seconds": 15 }` | **(SYS-02)** Server chủ động "nổ cuốc", bắn thông tin chuyến đi cho tài xế xem trên App (Tài xế có 15s để accept/bỏ qua bằng API Rest).         |
| `server:trip_status_changed` | Server -> Khách hàng     | `{ "trip_id": "string", "status": "ACCEPTED \| ARRIVED \| IN_PROGRESS \| COMPLETED", "timestamp": "ISO8601" }`                                                | **(CUS-04)** Trạng thái chuyến đi đổi. Bắn Push/In-app cho khách. Ví dụ: Khi tài xế "Đã đến nơi" hoặc Khách "Đã lên xe".                        |
| `server:driver_location`     | Server -> Khách hàng     | `{ "trip_id": "string", "driver_id": "string", "latitude": 10.763, "longitude": 106.662, "heading": 90 }`                                                     | Server phát (broadcast) lại vị trí mới nhất của tài xế vào room `trip_${id}` để App Khách hàng vẽ icon xe di chuyển trên bản đồ (Real-time).    |
| `server:offer_expired`       | Server -> Tài xế         | `{ "offer_id": "string", "reason": "TIMEOUT" }`                                                                                                               | Báo cho App Tài xế biết cuốc xe vừa hiện đã hết thời gian nhận, yêu cầu App đóng Pop-up nhận cuốc.                                              |
| `server:trip_cancelled`      | Server -> Khách / Tài xế | `{ "trip_id": "string", "cancelled_by": "CUSTOMER \| DRIVER", "reason": "string" }`                                                                           | Thông báo huỷ chuyến đột xuất ngay lập tức từ một trong 2 phía.                                                                                 |
